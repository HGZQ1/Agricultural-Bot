```bash
cd "/home/hgzq/Agricultural Bot/Agricultural_Bot/ros2_ws"

``` 

Gazebo查看模型 

```bash
cd "/home/hgzq/Agricultural Bot/Agricultural_Bot"

source /opt/ros/jazzy/setup.bash

cd ros2_ws
colcon build --symlink-install
source install/setup.bash

cd ../sim_ws
colcon build --symlink-install
source install/setup.bash

ros2 launch agri_sim_bringup simulation.launch.py paused:=true
``` 
(这里面可能会有一个报错“[gazebo-1] [Err] [Physics.cc:1906] Attempting to create a mimic constraint for joint [gripper_right_finger_joint] but the chosen physics engine does not support mimic constraints, so no constraint will be created.”，不用理他)

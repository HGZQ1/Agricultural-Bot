D405 的 2 米扩展仿真量程（用于 YOLO 与三维定位流程开发）

先在当前仿真启动终端按 Ctrl+C 结束旧场景，再执行：

```bash
cd "/home/hgzq/Agricultural Bot/Agricultural_Bot"
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
source sim_ws/install/setup.bash

ros2 launch agri_sim_bringup simulation.launch.py rviz:=true \
  camera_config:="$(ros2 pkg prefix --share agri_sim_sensors)/config/d405_extended_sim.yaml"
```

此入口启用 0.07–2.0 m 深度，RViz 显示范围同步至 2 m；要继续使用 RGL 雷达，
在启动命令中追加 `lidar_mode:=rgl`。未指定相机配置时仍为原来的 0.07–0.50 m。
2 米模式为理想 RGB-D 仿真，不代表真实 D405 在该距离的精度。1

番茄田底盘运动测试（独立 ROS 域，两个终端都要设置）

启动终端：

```bash
cd "/home/hgzq/Agricultural Bot/Agricultural_Bot"
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
source sim_ws/install/setup.bash
export ROS_DOMAIN_ID=92
export GZ_PARTITION=agricultural_bot_tomato_field

ros2 launch agri_sim_bringup tomato_field.launch.py \
  gui:=true paused:=false use_control:=true use_kinematics:=true \
  use_lidar:=false use_camera:=false gz_partition:="$GZ_PARTITION"
```

控制终端：

```bash
cd "/home/hgzq/Agricultural Bot/Agricultural_Bot"
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
source sim_ws/install/setup.bash
export ROS_DOMAIN_ID=92
export GZ_PARTITION=agricultural_bot_tomato_field

ros2 control list_controllers
ros2 run teleop_twist_keyboard teleop_twist_keyboard --ros-args \
  -p stamped:=true -p frame_id:=base_footprint -p use_sim_time:=true \
  -p speed:=0.1 -p turn:=0.2
```

英文输入法下长按 `i` 前进、`,` 后退、`u/o` 前进转弯、`k` 停车。
先前进 1 m、停车，再倒车回入口，避免从出生位置直接倒车到地面边缘。
当前轮速上限对应约 0.254 m/s，使用 `speed:=1.0` 会限幅。
量化测试与判据见 [番茄田底盘测试说明](../Agricultural_Bot/docs/chassis_field_motion.md)。

番茄数量与高度随机化（测试参数，真实温室尺寸待定）

首次使用先构建资产与启动入口：

```bash
cd "/home/hgzq/Agricultural Bot/Agricultural_Bot"
source /opt/ros/jazzy/setup.bash
source ros2_ws/install/setup.bash
cd sim_ws
colcon build --symlink-install --packages-select agri_greenhouse_worlds agri_sim_bringup
source install/setup.bash
cd ..

python3 sim_ws/src/agri_greenhouse_worlds/scripts/generate_tomato_field.py \
  --randomize-fruits --fruit-visual mesh \
  --rows 2 --plants-per-row 3 --origin-x -1 --origin-y -5 \
  --fruit-count-min 2 --fruit-count-max 5 \
  --fruit-height-min 0.60 --fruit-height-max 1.10 \
  --seed 42 \
  --output artifacts/tomato_random_demo.sdf \
  --metadata artifacts/tomato_random_demo.json

export ROS_DOMAIN_ID=94
export GZ_PARTITION=agricultural_bot_random_fruits
ros2 launch agri_sim_bringup tomato_field.launch.py \
  world:="$PWD/artifacts/tomato_random_demo.sdf" \
  gz_partition:="$GZ_PARTITION" gui:=true paused:=true
```

高度指果实中心距离世界地面 Z=0 的高度，单位米。更换 `--seed` 可生成新分布；
同参数同种子可复现。删除行数、每行株数和两个 origin 覆盖项，可生成原布局 150 株。
果实为独立静态目标，当前调整不会改变植株株高，也没有摘取/脱落物理。
现在默认使用原番茄果体网格和红/青贴图；旧球体场景需要重新生成并重启 Gazebo。
`--fruit-visual sphere` 可切回纯色球体，不改变相同种子下的数量和位置。
完整参数、成熟概率和模型说明见
[果实随机化指南](../Agricultural_Bot/docs/tomato_fruit_randomization.md)。
